# 🔐 File Encryptor · Web Pro

> 一款完全运行在浏览器中的文件加密工具 —— 零依赖、零上传、零后端。所有加解密与密钥派生均在本地通过 [Web Crypto API](https://developer.mozilla.org/zh-CN/docs/Web/API/Web_Crypto_API) 完成，文件永远不会离开你的设备。

---

## 📖 简介

**File Encryptor · Web Pro** 是一个纯前端、单页应用形式的文件加密工具。它采用多层 AES-GCM 认证加密，配合 PBKDF2 密钥派生、可选的多轮压缩与数据填充，为你的文件提供强加密保护。

只需打开页面、选择文件、输入密码，点击「加密」即可得到一个加密文件。整个过程不涉及任何网络请求，密码与文件内容只存在于当前页面内存中。

> ⚠️ **重要提示**：本工具通过 `file://` 打开时 Web Crypto API 不可用，请务必通过 **HTTPS** 或 **localhost** 访问。

---

## ✨ 功能特性

### 核心加密能力
- **多层加密**：支持 1–50 层 AES-GCM 加密，每层使用独立派生的子密钥（FENC-layer-{i}），层层叠加。
- **AES-GCM 认证加密**：同时提供机密性与完整性保护，任何篡改都会导致解密失败。
- **密钥长度可选**：AES-128 / AES-192 / AES-256-GCM。
- **PBKDF2 强密钥派生**：支持 SHA-256 / SHA-384 / SHA-512，迭代次数 10,000 – 5,000,000 可调。
- **层密钥派生模式**：HMAC-SHA256 或 HKDF，可随哈希算法自动联动。
- **AAD 附加认证数据**：将额外信息（如用户 ID、项目名）纳入 GCM 认证范围，不匹配则解密失败。

### 数据处理
- **压缩预处理**：加密前可选择 Deflate-Raw / Deflate / GZIP，或「⚡ 超级压缩」（多轮 GZIP 叠加，自动在收益递减时停止）。
- **数据填充**：可选 16 / 64 / 128 / 192 / 255 字节块大小填充，隐藏真实文件长度，抵御尺寸分析攻击。
- **输出格式**：支持二进制 `.enc` 或十六进制文本 `.enc.hex`。

### 使用体验
- **快速预设**：🚀 快速 / 🛡 标准 / 🔒 安全 / 💎 极限，一键套用参数组合。
- **密码工具**：实时密码强度评估、随机强密码生成、明文/密文切换。
- **自动格式识别**：解密时自动识别二进制或十六进制文件，无需手动切换。
- **主题切换**：系统 / 浅色 / 深色，跟随系统偏好并记忆选择。
- **进度反馈**：实时进度条与分阶段状态提示。
- **滚动条美化**：始终预留滚动条空间避免布局跳动，支持隐藏滚动条（保留滚动能力）。

### 兼容性
- **向下兼容 v1 格式**：自动识别并解密旧版本生成的文件。
